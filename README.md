# PROJECT SPIRIT
## Secure AWS Three-Tier Architecture with HTTPS

### Project Overview

Project Spirit is a hands-on AWS cloud engineering project focused on designing, deploying and securing a three-tier web application.

The application allows users to submit information through a web interface, store records in a MySQL database and retrieve previously saved records.

The project demonstrates the deployment of a frontend, backend and database across a segmented AWS cloud environment, incorporating load balancing, network security and HTTPS.

### Architecture

- **Frontend:** HTML, CSS and Vanilla JavaScript
- **Web Server:** Apache HTTP Server
- **Backend:** Python and Flask
- **Database:** Amazon RDS for MySQL
- **Public Load Balancer:** AWS Application Load Balancer
- **Internal Load Balancer:** AWS Internal Application Load Balancer
- **HTTPS:** AWS Certificate Manager
- **DNS:** Amazon Route 53

### Project Objectives

- Build a functional three-tier web application.
- Design and deploy an AWS VPC across multiple Availability Zones.
- Configure public and private subnets.
- Deploy frontend and backend EC2 instances.
- Implement an internal and public Application Load Balancer.
- Configure secure database connectivity.
- Enable HTTPS access using AWS Certificate Manager.
- Apply AWS security and access management controls.
